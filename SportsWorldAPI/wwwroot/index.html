SportsWorld API

Athletes

Method Endpoint Description
GET /api/athletes Henter alle utøvere.
GET /api/athletes/{id} Henter en utøver basert på ID.
GET /api/athletes/search?name={name} Søker etter utøvere basert på navn.
POST /api/athletes Oppretter en ny utøver.
PUT /api/athletes/{id} Oppdaterer en eksisterende utøver.
DELETE /api/athletes/{id} Sletter en utøver.

Venues

Method Endpoint Description
GET /api/venue Henter alle venues.
GET /api/venue/{id} Henter venue basert på ID.
GET /api/venue/ByName/{name} Søker etter venue basert på navn.
POST /api/venue Oppretter en venue.
PUT /api/venue/{id} Oppdaterer en venue.
DELETE /api/venue/{id} Sletter en venue.

Finance

Method Endpoint Description
GET /api/finance Henter nåværende finance status.
PUT /api/finance Oppdaterer finansene.

Images

Method Endpoint Description
POST /api/image Laster opp et bilde. Returnerer filstien.
